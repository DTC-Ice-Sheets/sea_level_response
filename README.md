# DTC-IS Sea Level Response Module

The `sea_level_response` module is a sub-component of the
[Digital Twin Component for Ice Sheets (DTC-IS)](https://dtc-ice-sheets.org/), an ESA-funded, EO-driven digital twin project.

This software package calculates sea-level changes arising from water mass inputs to the oceans and can be run in isolation from the digital twin.

For an in-depth overview of the sea_level_response module please [read the docs](https://dtc-ice-sheets.github.io/sea_level_response/).

The documentation includes sections on:

1. [Getting started](https://dtc-ice-sheets.github.io/sea_level_response/quick-start.html)
1. [Scientific overview](https://dtc-ice-sheets.github.io/sea_level_response/overview.html)
1. [API reference](https://dtc-ice-sheets.github.io/sea_level_response/api.html)

For a more interactive way of exploring the system, please visit the digital twin's [dashboard](https://dashboards.dtc-ice-sheets.org/).

## Installation for Use

You can install this package with pip:

``` bash
pip install sea_level_response
```

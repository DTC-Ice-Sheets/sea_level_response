DTC Ice Sheets: Sea-Level Response

The sea_level_response module is a sub-component of the Digital Twin Component for Ice Sheets (DTC-IS), an ESA-funded, EO-driven digital twin project.

This software package calculates sea-level changes arising from water mass inputs to the oceans and can be run in isolation from the digital twin.

For a more interactive way of exploring the system, please visit the digital twin’s dashboard.

The remainder of this documentation page provides an overview of the sea_level_response module and details about how to get it running locally.

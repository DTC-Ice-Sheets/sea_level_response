bin_loads_to_points(lat_deg: ndarray, lon_deg: ndarray, mass_gt: ndarray, masserr_gt: ndarray, bin_res_deg: float = 1.0) → tuple[ndarray, ndarray, ndarray, ndarray]

Bin loads into coarse lat/lon cells and return one point load per occupied cell (at the cell centre).

Masses are summed. Errors are combined as sqrt(sum(err^2)), i.e. assuming independent errors.

Parameters:

  • lat_deg (np.ndarray) – Latitude of the loads in degrees (any shape; they are flattened).

  • lon_deg (np.ndarray) – Longitude of the loads in degrees (any shape; they are flattened).

  • mass_gt (np.ndarray) – Mass in Gt, same shape as lat/lon.

  • masserr_gt (np.ndarray) – Mass error in Gt, same shape as lat/lon.

  • bin_res_deg (float) – Resolution at which mass-balance loads are binned to point loads.

Returns:

lat_centres, lon_centres (degrees), mass (Gt), mass error (Gt) of the occupied bins.

Return type:

tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]

compute_mean_mass_balance_over_time_window(ds: Dataset, start_time: datetime | None = None, end_time: datetime | None = None) → Dataset

Compute the mean mass balance and, if present, its error over a time range, collapsing the time dimension.

Parameters:

  • ds (xr.Dataset) – Input mass balance dataset with a time dimension. The mass-balance error variable is optional.

  • start_time (datetime | None) – Start time for slicing, by default None. If both start_time and end_time are provided, the dataset is sliced accordingly before computing the mean. Otherwise, the entire time range is used.

  • end_time (datetime | None) – End time for slicing, by default None. If both start_time and end_time are provided, the dataset is sliced accordingly before computing the mean. Otherwise, the entire time range is used.

Returns:

Dataset with the same spatial dimensions (‘point’, ‘x’, ‘y’), where the ‘time’ dimension has been removed and each variable represents the mean value across the specified years. The error variable is only included if it was present in the input.

Return type:

xr.Dataset

preprocess_location_timeseries(annual_slr_ds: Dataset, lat0: float, lon0: float) → dict

Preprocess annual SLR data for a specific location, returning plot-ready time series.

This function extracts time series data at the nearest grid point to the specified coordinates, computes cumulative sums, calculates linear trends, and returns data ready for plotting.

Parameters:

  • annual_slr_ds (xr.Dataset) – Annual SLR dataset containing ‘ndot’, ‘udot’, ‘sdot’ and their uncertainties.

  • lat0 (float) – Target latitude in decimal degrees (-90 to 90).

  • lon0 (float) – Target longitude in decimal degrees (-180 to 180).

Returns:

Dictionary containing: - ‘years’: List of year labels (integers) - ‘sdot_cumulative’: Cumulative relative SLR (mm) - ‘ndot_cumulative’: Cumulative absolute SLR (mm) - ‘udot_cumulative’: Cumulative vertical deformation (mm) - ‘sig_sdot_cumulative’: Cumulative uncertainty for sdot (mm) - ‘sig_ndot_cumulative’: Cumulative uncertainty for ndot (mm) - ‘sig_udot_cumulative’: Cumulative uncertainty for udot (mm) - ‘slope_sdot’: Linear trend for relative SLR (mm/yr) - ‘slope_ndot’: Linear trend for absolute SLR (mm/yr) - ‘slope_udot’: Linear trend for vertical deformation (mm/yr) - ‘actual_lat’: Actual latitude of nearest grid point - ‘actual_lon’: Actual longitude of nearest grid point

Return type:

dict

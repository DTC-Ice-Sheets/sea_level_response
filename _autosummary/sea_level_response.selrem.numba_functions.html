sea_level_response.selrem.numba_functions

Functions accelerated with Numba for SELREM computation.

These have been separated because Numba JIT-compiled functions can have issues with type hints. Keeping them here allows us to keep type hints in other parts of the SELREM logic.

Functions

accumulate_fields(lat_arr, lon_arr, ...)

Accumulate sea-level and deformation fields from mass change points using SELREM parameterizations.
sea_level_response.selrem.numba_functions.accumulate_fields(lat_arr, lon_arr, mass_arr, mass_err_arr, sin_lat, cos_lat, lon_rad, y21_real, ndot_fit, udot_fit, ndot_unc, udot_unc)

Accumulate sea-level and deformation fields from mass change points using SELREM parameterizations.

Parameters:

  • lat_arr (np.ndarray) – Array of latitudes (in radians) for mass change points.

  • lon_arr (np.ndarray) – Array of longitudes (in radians) for mass change points.

  • mass_arr (np.ndarray) – Array of mass changes (in Gt) for each point.

  • mass_err_arr (np.ndarray) – Array of mass change uncertainties (in Gt) for each point.

  • sin_lat (np.ndarray) – 2D array of sine of latitude for the target grid.

  • cos_lat (np.ndarray) – 2D array of cosine of latitude for the target grid.

  • lon_rad (np.ndarray) – 2D array of longitude (in radians) for the target grid.

  • y21_real (np.ndarray) – 2D array of real part of spherical harmonic Y21 for the target grid.

  • ndot_fit (np.ndarray) – SELREM fit parameters for ndot.

  • udot_fit (np.ndarray) – SELREM fit parameters for udot.

  • ndot_unc (np.ndarray) – SELREM uncertainty parameters for ndot.

  • udot_unc (np.ndarray) – SELREM uncertainty parameters for udot.

Returns:

Tuple containing ndot_total, udot_total, rot_total, ndot_radial_unc_total, udot_radial_unc_total, ndot_vmb_unc_total, udot_vmb_unc_total arrays.

Return type:

tuple of np.ndarray

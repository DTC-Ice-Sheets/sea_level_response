Command line entry point for location specific sea-level time-series computation.
main(annual_slr_gz_path: Path, output_path: Path, latitude: float | None = None, longitude: float | None = None) → None

Command line entry point for location specific sea-level time-series computation.

Parameters:

  • annual_slr_gz_path (Path) – Path to the local GeoZarr dataset containing global, annual sea-level rise data.

  • output_path (Path) – Where to save the output time series data as JSON.

  • latitude (float | None) – Target latitude for time series extraction.

  • longitude (float | None) – Target longitude for time series extraction.

Raises:

ValueError – If either latitude or longitude is not provided.

sea_level_response.selrem.selrem.compute_annual_slr(ds: Dataset, scale_factor: float = 1.0) → Dataset

Compute annual SELREM SLR results and return as an xarray.Dataset.

Parameters:

  • ds (xr.Dataset) – xarray.Dataset with dims (“point”, “year”), variables “VMB”, “VMBer”, “y”, “x”

  • scale_factor (float) – Scaling factor to apply to mass balance values (default: 1.0).

Returns:

xarray.Dataset with dims (“year”, “y”, “x”) containing: - ndot, udot, sdot - sig_ndot, sig_udot, sig_sdot - rot_total

Return type:

xr.Dataset

sea_level_response.selrem.selrem.compute_global_slr(ds: Dataset, scale_factor: float = 1.0) → Dataset

Compute global sea-level response from a VMB dataset.

Parameters:

  • ds (xr.Dataset) – Single-snapshot VMB dataset (no ‘year’ dimension required).

  • scale_factor (float) – Scaling factor for mass balance, default 1.0.

Returns:

{

“sdot”: (lat, lon) gridded relative SLR, “ndot”: (lat, lon) absolute SLR, “udot”: (lat, lon) vertical deformation, “sig_sdot”: (lat, lon) uncertainty, “global_mean_sdot”: scalar, “global_mean_ndot”: scalar, “global_mean_udot”: scalar

}

Return type:

xr.Dataset

sea_level_response.selrem.selrem.run_emulator(loading_points: DataFrame | dict, ndot_fit: ndarray, udot_fit: ndarray, ocean_mask: ndarray, ndot_unc: ndarray, udot_unc: ndarray, target_res: float = 0.5, compute_res: float = 5.0) → tuple

Compute the necessary parameters for the emulator.

Parameters:

  • loading_points (pd.DataFrame | dict) – DataFrame or dictionary containing loading point data with keys/columns: ‘lat’ (latitude in degrees), ‘lon’ (longitude in degrees), ‘Mass(Gt)’ (mass in gigatonnes), and optionally ‘Mass_err(Gt)’ (mass error in gigatonnes).

  • ndot_fit (np.ndarray) – SELREM fit parameters for ndot.

  • udot_fit (np.ndarray) – SELREM fit parameters for udot.

  • ocean_mask (np.ndarray) – 2D array representing the ocean mask (1 for ocean, 0 for land).

  • ndot_unc (np.ndarray) – SELREM uncertainty parameters for ndot.

  • udot_unc (np.ndarray) – SELREM uncertainty parameters for udot.

  • target_res (float) – Target resolution in degrees for the final output grid, by default 0.5.

  • compute_res (float) – Computation resolution in degrees for intermediate calculations, by default 5.0.

Returns:

Tuple containing the following elements: - lat_arr : np.ndarray

1D array of latitude (in radians) for the loading points.

  • lon_arrnp.ndarray

    1D array of longitude (in radians) for the loading points.

  • mass_arrnp.ndarray

    1D array of mass (in Gt) for the loading points.

  • mass_err_arrnp.ndarray

    1D array of mass error (in Gt) for the loading points.

  • sin_latnp.ndarray

    2D array of sine of latitude for the target grid.

  • cos_latnp.ndarray

    2D array of cosine of latitude for the target grid.

  • lon_radnp.ndarray

    2D array of longitude (in radians) for the target grid.

  • y21_realnp.ndarray

    2D array of real part of spherical harmonic Y21 for the target grid.

  • ndot_fitnp.ndarray

    SELREM fit parameters for ndot.

  • udot_fitnp.ndarray

    SELREM fit parameters for udot.

  • ndot_uncnp.ndarray

    SELREM uncertainty parameters for ndot.

  • udot_uncnp.ndarray

    SELREM uncertainty parameters for udot.

Return type:

tuple

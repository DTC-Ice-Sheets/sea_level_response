sea_level_response.helpers.get_dataset_crs(dataset: Dataset) → CRS | None

Retrieve the CRS details from the dataset.

This function has been taken from the Data Download Module. It first checks for CRS written with rioxarray. Next, it checks the dataset for a grid mapping attribute If the CRS is not found in the grid mapping, it checks the dataset attributes for a _CRS attribute containing the WKT. If the CRS is still not found, it checks one of the data variable’s attributes for a _CRS attribute with a wkt key (to match the current format of S1 ice velocity data on EODS).

Parameters:

dataset (xr.Dataset) – The dataset from which to retrieve the CRS.

Returns:

The CRS of the dataset.

Return type:

pyproj.CRS | None
